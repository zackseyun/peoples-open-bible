# Enoch 29:1-2 source application (bounded)

The initial independent Codex scan pass accepted 29:1 but rejected 29:2; its
verdict and original log are preserved. The corrected final pass accepts both
units, their complete printed page-70 ending and the chapter XXX boundary.
This is review of Charles 1906 edited Geʿez and its printed Greek parallel,
not independent manuscript collation or human-specialist certification.

The source editor retains the *transmitted*, dagger-marked “judgment” reading
rather than silently adopting Charles’s aromatic conjecture. English, notes,
critical daggers, the untranslated bracketed expression and only the editor-
supplied final noun are separately disclosed. Greek καρύαις is conservatively
rendered “nut-bearing trees,” avoiding a botanically certain almond; see the
[LSJ lexical entry](https://logeion.uchicago.edu/%CE%BA%CE%B1%CF%81%CF%85%CC%81%CE%B1).
Verse 1 only corrects the routing and explanation of its three footnote anchors.

`tools/textual_restoration/enoch_29_transaction.py` verifies package hashes,
source scans, independent reviewer result, exact preimages, note anchors and a
chapter-29-only export delta before apply. Application alone is not Graphic
Reader publication. Artwork remains held until this source is merged, hosted
and checked; no existing public chapter may be overwritten.
